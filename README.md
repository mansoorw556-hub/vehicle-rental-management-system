# vehicle-rental-management-system
A Python-based vehicle rental management system for managing vehicles, rentals, pricing, taxes, and statistics

#about Project
Vehicle Rental & Management System is a Python-based console application designed to manage vehicle rental operations. The system allows users to add and manage vehicles, search for vehicles, rent and return vehicles, calculate rental prices and taxes, and generate useful statistics and summaries.

Main Features:

Add and manage vehicle records
Search vehicles
Rent vehicles
Return rented vehicles
Calculate rental prices based on rental days
Calculate vehicle rental tax
Find the highest and lowest rental prices
Calculate average rental price
Count total vehicles
Sort vehicles by rental price and owner name
Count vowels in owner names
Generate statistics and summary reports
Store and read data using file handling
